# 評価プロトコル

Matryoshka 次元（128 / 256 / 512 / 768）を**同一条件**で比較するための手順と定義です。
実装は `src/embeddinggemma_lab/evaluation.py`・`metrics.py`、実行は `scripts/run_evaluation.py` または Evaluation ページ。

## 1. 評価セット

`datasets/sample/eval/*.jsonl`（1 行 1 クエリ）

```json
{"query_id": "t01", "query": "ロボットが物体を落とす", "relevant": {"d01": 2, "d02": 2, "r03": 1}}
```

- `relevant` は段階的関連度（2 = 正解、1 = 部分的に関連、記載なし = 0）。
- 二値指標（Recall / P / MRR）では grade > 0 を関連とみなす。

| セット | コーパス | クエリ | 備考 |
|---|---|---|---|
| `text` | サンプル文書 41 件（日英、10 カテゴリ） | 20（日英） | 言語横断の検索を含む |
| `image` | 合成画像 17 枚 | 14（日英） | |
| `video` | 合成グリッパ動画 8 本 | 8（日英） | 成功 / 滑り / 落下 / 回復。集約方式を選択 |

独自の JSONL を Evaluation ページからアップロードできます（コーパスに無い ID は警告）。

## 2. 指標

`ranked` はコーパス全件を順位付けしたリスト。

| 指標 | 定義 |
|---|---|
| Recall@K | 上位 K に含まれる関連アイテム数 / 関連アイテム総数 |
| P@K | 上位 K に含まれる関連アイテム数 / K |
| MRR | 最初の関連アイテムの順位の逆数（全順位で計算）をクエリ平均 |
| nDCG@K | DCG = Σ (2^rel − 1) / log2(i + 1)、理想順位の DCG で正規化 |

すべて手計算値と照合するユニットテストあり（`tests/test_metrics.py`）。

## 3. 速度・保存量

| 項目 | 測定方法 |
|---|---|
| クエリエンコード | **キャッシュを通さず**生のエンコーダで、バッチサイズ 1、ウォームアップ後に `repeats × クエリ数` 回測定し p50 / p95。切り詰めはエンコード後なので**次元に依存しない**（1 回だけ測定し全次元に同じ値を記載） |
| インデックス構築 | 次元ごとに、キャッシュ済みベクトルの読み込み → 行列化までの時間（初回エンコード時間は含まない） |
| 検索 | 次元ごとに、各クエリで 1 回ウォームアップ後 `repeats` 回測定し p50 / p95 |
| 保存量 | float32 ベクトル 1 本あたり `dim × 4` bytes、インデックス全体は × アイテム数（メタデータ・インデックス構造は除く） |
| GPU ピークメモリ | `torch.cuda.max_memory_allocated()`（CUDA 時のみ） |

## 4. 再現性のための記録

`report.json` の `run` に以下を保存します。

- モデル ID・**revision（コミットハッシュ）**・デバイス名・dtype・バッチサイズ
- 検索方式（NumPy 完全内積）、評価セット名（動画は集約方式・フレーム間隔を含む）
- `EvalConfig`（次元・K・ウォームアップ回数・測定回数）
- Python / OS / torch・transformers・sentence-transformers・numpy のバージョン
- 実行時刻（UTC）

同じ設定で再実行すると品質指標は完全に一致します（`tests/test_evaluation.py::test_rerun_gives_identical_quality`、
実モデルでも確認済み）。速度は環境依存のため p50 / p95 で比較してください。

## 5. 出力

`reports/<timestamp>-<eval_set>/`（Git 管理外）

| ファイル | 内容 |
|---|---|
| `summary.csv` | 次元ごとの平均指標・レイテンシ・保存量 |
| `per_query.csv` | 次元 × クエリごとの指標 |
| `failures.csv` | 1 位が関連アイテムでないクエリ（期待正解・上位検索結果と関連度） |
| `report.json` | 上記すべて + 実行環境・設定 |

## 6. 注意

- スコア（コサイン類似度）は関連度の指標であり、正解確率ではありません。
- サンプル評価セットは小規模なデモ用で、統計的に有意な差を主張するものではありません。
- UMAP の見かけのクラスタは評価に使いません（Embedding Analysis ページは定性的な確認用）。
